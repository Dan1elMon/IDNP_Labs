# Laboratorios de Introducción al Desarrollo de Nuevas Plataformas

Repositorio destinado al desarrollo, organización y almacenamiento de los laboratorios realizados en el curso **Introducción al Desarrollo de Nuevas Plataformas**.

## Descripción

Este repositorio contiene los diferentes laboratorios y ejercicios prácticos desarrollados durante el curso, orientados al aprendizaje de nuevas tecnologías y plataformas para el desarrollo de aplicaciones.

Los trabajos permiten aplicar conceptos de desarrollo de software mediante herramientas, frameworks y tecnologías actuales, siguiendo buenas prácticas de programación y organización de proyectos.

## Objetivos

* Comprender los fundamentos del desarrollo en nuevas plataformas.
* Aplicar conceptos de programación mediante ejercicios prácticos.
* Explorar diferentes herramientas y tecnologías de desarrollo.
* Desarrollar aplicaciones utilizando frameworks y plataformas modernas.
* Aplicar buenas prácticas de organización y documentación de código.
* Utilizar Git y GitHub para el control de versiones.
* Fortalecer las habilidades para el desarrollo de aplicaciones multiplataforma.

## Tecnologías

Las tecnologías utilizadas pueden variar de acuerdo con cada laboratorio. Entre ellas pueden encontrarse:

* Kotlin
* Android Studio
* Jetpack Compose
* Git
* GitHub
* Otras tecnologías y frameworks indicados durante el curso.


Cada laboratorio tendrá su propia carpeta y, cuando sea necesario, un archivo `README.md` con la descripción, instrucciones y resultados correspondientes.



> La tabla se actualizará conforme se desarrollen los laboratorios del curso.

## Requisitos

Para trabajar con los proyectos del repositorio se recomienda contar con:

* Git
* GitHub
* Android Studio
* JDK compatible con el proyecto
* Gradle
* Un equipo con los recursos necesarios para ejecutar Android Studio y los proyectos correspondientes.

## Instalación

Clonar el repositorio:

```bash
git clone URL_DEL_REPOSITORIO
```

Ingresar al directorio:

```bash
cd Introduccion-Desarrollo-Nuevas-Plataformas
```

Posteriormente, abrir el laboratorio correspondiente desde Android Studio o el entorno de desarrollo indicado para cada proyecto.

## Flujo de trabajo con Git

Para obtener los últimos cambios:

```bash
git pull
```

Crear una rama para trabajar en un laboratorio o funcionalidad:

```bash
git checkout -b nombre-de-la-rama
```

Agregar los cambios:

```bash
git add .
```

Realizar un commit:

```bash
git commit -m "Descripción de los cambios"
```

Subir los cambios:

```bash
git push origin nombre-de-la-rama
```
